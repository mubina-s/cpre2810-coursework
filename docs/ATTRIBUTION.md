# Attribution & Academic Context

This repository is a curated portfolio of selected coursework completed for **CPRE 2810 at Iowa State University**.

## Quartus / Intel / Altera Generated Content

The original course workspace was created using Intel/Altera Quartus Prime.

Some `.v` files in the coursework were generated from Quartus block-diagram designs. Those files contain Intel/Altera copyright notices and tool-generated comments. Those notices have been retained.

Including a generated Verilog file here does not imply that the surrounding Quartus software, libraries, or generated infrastructure was authored by me.

## Course-Provided Frameworks

The source archive contains instructor-provided resources, lab instructions, FPGA pin-assignment material, and a later processor/CPU framework with many pre-existing components.

The public portfolio does not republish the complete framework. In particular, the large CPU-oriented workspace is summarized in the main README rather than copied wholesale.

## Public Portfolio Selection

The original archive contains roughly thousands of files, including:

- Quartus database files
- Compilation outputs
- reports
- caches
- FPGA programming artifacts
- block-symbol files
- project metadata
- lab reports
- homework
- instructor resources
- duplicate projects and ZIP archives

The public repository keeps only selected source files that demonstrate my progression through Boolean logic, display decoding, arithmetic circuits, multiplexers, sequential logic, counters, clocking, and register-file design.

## Academic Integrity

This repository is intended to document my learning and technical growth, not to serve as a solution bank for current students.

Graded reports, homework solutions, and complete course frameworks are intentionally excluded.
